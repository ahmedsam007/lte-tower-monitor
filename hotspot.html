1Join and sign in

Join the public Wi-Fi. If a sign-in page opens, enter the username and password from your card there.

2Turn on Mobile Hotspot

Windows shares the connection this computer uses for the internet, over the same Wi-Fi card. Most Wi-Fi cards can do both at once.

2Share it from this Mac

A Mac can't send a Wi-Fi connection back out over its own Wi-Fi. It can share it with a device on a cable (Ethernet, USB or Thunderbolt): in Internet Sharing, share your connection from Wi-Fi to that cable port, then turn Internet Sharing on. To share over Wi-Fi, use an Android phone or a Windows computer instead.

2Share it

Sharing can be switched on here on Windows. On this computer, use its own network settings.

3Connect the other device

On the phone or other computer, join the network name shown above with its password. Open a website on it to check that it works. Some public Wi-Fi providers limit sharing or the number of devices.

To check the internet, this page uses Windows' own check (the same one behind the network icon on the taskbar).
